# Security Policy

If you discover a security vulnerability, please **do not open a public GitHub issue**.

Instead, report it privately via one of the following:

- **GitHub Private Vulnerability Reporting**: Go to the "Security" tab of this repo → "Report a vulnerability"
- **Email**: ben@benlawrence.nz

Please include:
- A description of the vulnerability and its potential impact
- Steps to reproduce (proof-of-concept code, if possible)
- Any suggested fix or mitigation, if known

## What to Expect
- I'll acknowledge your report within a few days.
- I'll investigate and let you know if it's confirmed as a valid issue.
- Once fixed, I'll credit you in the release notes (unless you prefer to stay anonymous).
- This is a personal/open-source project maintained in my spare time, so response times may vary — thanks for your patience.
